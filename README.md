# Armel Promeneur — prototype du site

Prototype de travail du site d'Armel Promeneur, peintre et sculpteur : galerie et vente d'œuvres.
Réalisé par CyberActivities (Dylan Borcard, Fribourg).

- En ligne : https://dylanborcard.github.io/armel-promeneur/
- **Statuts « disponible / vendue » et prix fictifs**, marqués « exemple ».
- Titres, années, techniques, dimensions et biographie : textes provisoires `[entre crochets]`, à fournir par l'artiste.
- Le formulaire de contact n'envoie rien : l'envoi est simulé.
- Site statique sans étape de build : `index.html`, `styles.css`, `app.js`, `data.js` (données des œuvres), `img/`.

Les œuvres et les photos appartiennent à Armel Promeneur. Toute reproduction demande son accord.
